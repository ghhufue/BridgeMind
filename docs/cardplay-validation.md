## 正确性验证

完整回归命令：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m bridgemind.cardplay audit
```

本轮最终结果：**81 项通过**（出牌测试 23 项，原有测试 58 项），完整回归耗时约 14.8 秒。

覆盖范围：

- 完整 52 张牌、各庄家、五种将牌/无将、加倍/再加倍及局况；本地逐墩和终局分数与 OpenSpiel 对照。
- 首攻隐藏明手、庄家控制明手、两个防守者的信息隔离；交换不可见手牌时，观察和网络策略输出保持一致。
- 非法动作不改变状态、强制跟牌、规则约束采样满足张数/已知牌/缺门；权重为零且无可行分配时拒绝。
- 动态完整叫牌 token（包含 Pass）、padding 对输出的影响、检查点往返与合法动作掩码。
- 数据分片往返、只包含当前出牌前缀、隐藏牌只作标签、末张牌无未知牌时归属损失为零。
- 实际双室自对局为零 IMP、交换双方时收益翻转；PPO 只收集当前模型动作，冻结对手参数不变。
- SL、蒸馏和 PPO 的 CPU 连续两步与一步后恢复到两步，模型参数逐位一致；更改续训配置被拒绝。蒸馏使用真实 TCP DDS 服务。CUDA 或跨硬件不保证逐位一致。
- 真实 TCP DDS 求解逐牌得分与直接原生接口对照，覆盖庄家/防守视角、有局和未完成的当前墩。
- 本轮修复了监督评估忽略 CLI `--seed`，拒绝负概率/非有限蒸馏标签，以及越界训练样本和重放前缀索引。

此外，对本机训练/验证/测试全部 **1,256 副 / 65,312 条**记录重新逐局重放。每一步对比分片与新生成的所有编码字段、动作、牌局 ID、真实归属标签及最终价值标签，全部一致。测试集合仅用于正确性与集合隔离检查；未用于训练或棋力评估。复核结果及耗时保存在汇总的 `datasets` 字段。

## 短实验结论

| 实验 | 结果 | 能支持的结论 |
|---|---|---|
| SL，固定种子抽样 512 条验证决策 | 初始 NLL 1.156484、准确率 43.164%；第 75 步 NLL 1.105088、准确率 51.563% | 监督拟合改善；未证明出牌棋力提高 |
| SL best 对随机策略，64 副双室 | -1.390625 IMP/副；95% 区间 [-2.984375, 0.0625] | 短训练没有建立相对随机策略的优势 |
| SL best 贪心对自身 | 见 `sl-self-validation.json`；零 IMP | 支持两室座位和计分的一致性 |
| PPO 第 3 次更新，对初始锚点，16 副在线验证 | +2.3125 IMP/副；95% 区间 [0.4375, 4.5] | 是训练期间反复使用的小验证面板，不能单独用于棋力结论 |
| 同一 PPO 对锚点，扩大至 64 副验证牌 | +0.015625 IMP/副；95% 区间 [-1.172266, 1.234375] | 没有明确优势；与上述 16 副重叠，不是独立留出集 |
| DDS / hybrid 对随机，分别 2 / 1 副 | 均完成真实两室出牌、服务返回正常 | 仅说明集成可运行，样本量不足以比较棋力 |
| 叫牌模型 → 出牌模型 | 完成 52 张，3S、西家庄家、实际终局见 `full-game-demo.json` | 后端叫牌到出牌与计分已连接 |

SL 第 100 步的 NLL 为 1.115855、准确率 51.367%、未知牌归属 NLL 0.780899；初始归属 NLL 为 1.508586。验证按固定种子有放回抽样，可能含重复决策。归属 NLL 下降不能证明归属概率经过校准或能提升搜索。

DDS 独立进程冒烟记录：2 个工作线程，286 个提交项全部成功，251 次原生调用、35 次在途合并。这里只是两样本搜索及短蒸馏验证的负载，不是 32/64 样本完整出牌的性能基准。历史报告的 UTC 时间在指标原样保留。

当前 `best.pt` 的选择依据分别为 SL/蒸馏的模仿 NLL、PPO 的小面板对锚点 IMP。后续需要扩大训练与独立验证、多随机种子、固定对手面板、叫牌历史消融和搜索样本量/耗时对照。PIMC 有策略融合偏差，不能把全知 DDS 结果当成受限信息策略的真实上限或实战能力。
