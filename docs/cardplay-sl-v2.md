## 训练协议

入口 `python -m bridgemind.sl_v2`，独立于已有训练器、评分器和基础题库实现，保持原冻结协议有效。

| 项目 | 固定设置 |
|---|---|
| 初始化 | `runs/play-sl-long-20261025/best.pt`，副本为本次目录 `init.pt` |
| 初始化 SHA256 | `156bd1cdf1418d68e9558f97d8d0a1e720584f1ed82a3f38b80504d59d0c4360` |
| 设备、优化器 | RTX 5070、CUDA、Adam、学习率 `1e-5`、梯度范数上限 1 |
| 预算 | 累计 7,200 秒，包含初始化验证、周期验证和训练循环；最后额外完成验证与存盘 |
| 每批 64 条 | 48 条真实决策、16 条基础课程；课程按 8 类战术均匀采样 |
| 真实数据 | 已有 WBridge5 轨迹，训练 10,000 副 / 520,000 条决策，验证 1,024 副 |
| 课程 | 704 个训练局面（256 个不同完整发牌对称类），176 个验证局面（64 类） |
| 课程种子 | 训练 260001–260032；验证 270001–270008 |
| 花色增强 | 24 种花色双射；同步变换手牌、历史出牌、将牌、缺门、合法动作、归属和监督答案 |
| 损失 | 所有样本的策略损失；真实样本另加 `0.2 × belief + 0.1 × value` |
| 存盘 / 验证 | 每 120 秒 / 每 300 秒；状态和进度约每 30 秒写入 |

每批真实样本中的 24 条保留原始叫牌和体系，另外 24 条做随机花色增强。桥牌叫牌花色等级与 SAYC 含义不具备任意置换对称性，所以增强样本使用合法的合成定约摘要，并把叫牌体系标为未知；出牌历史仍完整保留。跨高低花转换时根据同一实际墩数重算终局价值标签。

课程只接收可见信息证书通过的动作，多个最优动作共同作为接受集合，不强行选择唯一答案。课程不使用占位的归属或价值标签训练辅助头。认证时使用全知 DDS，策略输入不包含隐藏手牌或证书答案。

真实训练与验证按完整发牌的 24 花色 × 4 座位变换审计，交集为零；课程排除了真实数据、已公开基础题、诊断题和评分题对应的发牌对称类。这是已有 8 类题型的新种子验证，不能声称是未见题型测试；真实验证集也沿用历史验证集。

## 验证与检查点

每轮固定检查 4,096 条原始真实决策、对应的 4,096 条增强决策，以及全部 176 × 24 = 4,224 个课程验证变体；另在 128 副真实验证牌上与冻结的初始化模型进行双室 IMP 对战。

- `best.pt`：基础课程宏平均正确率不低于初始模型时，选择验证 IMP 最高的检查点；并列时比较课程正确率、增强真实数据 NLL。
- `best-curriculum.pt`：基础课程宏平均正确率最高的检查点，供能力对照。
- `last.pt`：最新模型、优化器、随机状态、累计用时；用于恢复。
- `status.json`、`metrics.jsonl`、`stdout.log`、`stderr.log`：实时状态、指标和日志。
- `report.json`：正常停止或预算结束后生成的最终运行记录。
- `protocol.json`、`curriculum.json`：冻结的参数、数据与代码哈希、题目与证书。

128 副对战用于选模，不能当成独立实战验收。训练结束后已冻结检查点并完成基础体检、牌力评分和全新2,048副确认；未见题型的进一步验证仍待开展。

```powershell

Get-Content runs/play-sl-v2-20261026-2h/stderr.log -Tail 10
```

需要提前停止时创建 `STOP`，循环随后完成最终验证与保存：

```powershell
New-Item -ItemType File runs/play-sl-v2-20261026-2h/STOP
```

确认原训练进程已退出，再删除停止标记并恢复。`--seconds` 是累计预算，已运行时间会扣除；相同参数不会额外再跑两小时：

```powershell
Remove-Item -LiteralPath runs/play-sl-v2-20261026-2h/STOP -ErrorAction SilentlyContinue
.\.venv\Scripts\python.exe -u -m bridgemind.sl_v2 train --run runs/play-sl-v2-20261026-2h --seconds 7200 --resume
```

代码、环境、数据或协议改变时拒绝恢复，需准备新实验目录。课程准备需 DDS，训练本身无需 DDS；本次专用 18766 端口服务已在课程准备完成后关闭。
