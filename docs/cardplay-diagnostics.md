# 长训SL出牌实测与针对性牌局

日期：2026-10-26。检查点为 `runs/play-sl-long-20261025/best.pt`，SHA256 `156bd1cdf1418d68e9558f97d8d0a1e720584f1ed82a3f38b80504d59d0c4360`，CUDA贪心推理。对手为已冻结的 `rule-basic`，DDS为独立服务中的v3.1.0。没有训练、修改权重或改动评分器v1。

**当前最明确的弱点是：在第四家、已能根据公开牌确定可以拿墩时，模型仍会高概率选择放过；其次是保留大牌和对等价花色变化的一致性。** 这不能简单归因于隐藏牌推断困难，也不能概括为所有搭档配合都差。

## 实测方法与范围

从原128副评分牌中，在逐步诊断前固定选取索引34、41、37、51、1、79（索引从0开始）：4副不同类型输牌、1副平局、1副赢牌作对照。每副重新交换南北/东西打完两室，共12室、624张出牌，结果精确复现原评分记录。

每个非强制动作都先让模型和规则策略各自在同一合法观察上选牌，再由评测器单独读取真实局面求DDS逐动作余墩。DDS结果不进入策略输入。保留所选牌、前三概率、当前墩、可见手牌、DDS全部最优牌及得分损失。

每室从模型有DDS余墩损失的决策中，按得分影响优先、同分取较早位置，选至多两处。分别只改成一张DDS最优牌或规则建议牌，之后全部重新由原模型/规则作决定，不能沿用因局面改变而可能已非法的后续牌序。

总计26次单步干预：14次提高模型方实际得分，9次不变，3次变差。这些干预不是独立牌局，不能累加收益或外推为总体胜率。它们也说明全知DDS建议不保证在原信息受限策略的后续出牌下获益。

## 可以定位到具体牌的错误

### 大满贯防守：第四家用♦7放过♦8

索引34、南北由模型防守东家7♠。第4墩已有：西♦8、北♦4、东♣5。南家合法方块为♦7、♦10、♦K，已经是第四家，出♦10可确定拿到本墩，且足以击宕大满贯。

模型选择♦7，概率 **72.61%**；♦10仅15.69%。规则选择♦10。实战模型让庄家取得13墩；只把这张改为♦10，后续照旧由原策略继续，庄家变成12墩，该副双室由 **-17变成-2 IMP**。

同一室第5墩又有类似失误：已出♥9、♥4、♥7，模型持♥5、♥10，却以65.19%选择♥5。单改♥10也将该副从-17改善到-2 IMP。两次干预是各自从原始牌局独立重放，不能把两个收益相加。

### 无将做庄：明手第四家没有用♠Q盖住♠9

索引37、东家1NT，模型控制东西。第6墩：北♠2、东♠4、南♠9，明手西尚可出♠Q或♠K拿墩。模型以 **69.74%** 选择♠3，规则选择♠Q。

只改这张为♠Q，后续原策略继续，模型庄家从5墩变成8墩，双室由 **-5变成+1 IMP**。这不是要求模型猜中暗牌，而是已公开的当前墩及手里大小牌关系。

### 有将做庄：第四家可以将吃，却选择垫牌

索引51、北家1♠。第9墩：东♣9、南♦10、西♣A，北已无梅花且有♠3。第四家可确定将吃，模型却以 **55.44%** 选择垫♦6。

只改为♠3，模型庄家从5墩变成7墩、完成定约，该副由 **-5变成0 IMP**。

另在索引41的3NT防守中，第四家有♣7可盖过已出的♣6，模型选择♣3。单改♣7使庄家从10墩变成8墩，双室由 **-12变成-4 IMP**。

双方经过的局面不同，因此这个表不能直接当作同分布的失误率比较；DDS损失也可能需要暗牌知识才能避免。不过与上述明确的第四家实例及反事实相结合，优先补基础拿墩逻辑比单纯加深隐藏牌推断更有依据。

## 新构建的32个战术变体

构建4类残局，每类有4种全局花色置换、2种合法历史前缀，共32例。每例都有完整52张牌、合法叫牌、可重放前缀和合法观察，不是无法接入模型的孤立小残局。

花色变体对**完整发牌和完整历史**同时置换，无将定约不变；已用测试验证其精确对应。这样可以分离模型对任意花色名称的依赖。每例枚举所有满足可见牌、张数、公开缺门的暗牌分配，共检查512个“变体—暗牌世界”组合，不按模型采样结果挑暗牌。

| 训练/诊断主题 | 模型DDS最优选择 | 规则DDS最优选择 |
|---|---:|---:|
| 及时用A盖K，保住后续先手 | 6/8 | 8/8 |
| 第四家拿下关键墩 | **4/8** | 8/8 |
| 保留搭档进手，不无谓盖大牌 | **8/8** | 8/8 |
| 用足够大的最小牌赢墩，保留A | 6/8 | 8/8 |
| 合计 | **24/32** | **32/32** |

其中24例的建议牌在所有可行暗牌分配中都比指定错误牌有严格更高的全知余墩；其余8例从不更差，在部分分配中更好。这里的“全知续打逐世界比较”仍不是一般不完全信息最优策略证明，但这些残局及已知当前墩的关系足以排除“只是DDS知道真实暗牌”的简单解释。

一个失败例子：前三家已出♣3、♣8、♣K，模型第四家持♣A、♣Q、♥3，明手余♥A、♥2。先拿♣A，再兑现已升大的♣Q，最后♥3送明手♥A，可取剩余3墩。模型却选择♣Q，让♣K拿走；在实际构造牌中少取2墩。所有6种可行暗牌分配下，先出♣A都更好。

在这组严格花色置换试题中：原始红心版本8/8；换成黑桃7/8；换成梅花 **2/8**；换成方块7/8。这说明在这些受控例子中模型没有保持应有的花色对称性，**不能由此推断所有梅花实战都弱**。当前SL路径直接使用原始编码、没有花色置换增强；这一实现事实与观察相吻合，但“缺少增强是主因”仍需训练对照实验确认。

[tactical-cases.json](../artifacts/cardplay-diagnostics-v1/tactical-cases.json) 保存32例及每例模型概率、DDS标签、完整前缀、暗牌世界审计。[real-regression-cases.json](../artifacts/cardplay-diagnostics-v1/real-regression-cases.json) 另保存6个真实失败位置，便于精确复现。

## 下一步应优先补什么

1. **先补第四家决策课程。** 区分对手赢墩、搭档赢墩；覆盖最小足够赢牌、必须拿墩、合适将吃，以及合理忍让的反例。按是否影响成约/击宕和实际单步重放结果筛选关键样例，不能把所有DDS后悔值都当成可见信息错误。
2. **加入一致的花色置换增强。** 手牌、历史、定约将牌、合法掩码、动作标签与归属标签必须一起变换。先用无将精确对称测试验收，再扩展有将。不要只换输入手牌而保留旧标签。
3. **对关键决策单独验收。** 全局模仿准确率约70%掩盖了少数代价极大的选择。需要报告这类局面的通过率及实际IMP，而非只以验证NLL选最佳模型。
4. **再检查多步连贯性。** 一些DDS改牌没有实际收益，甚至变差，说明不能把最优单步标签直接等同于策略整体提升；应对改动后的后续轨迹继续评估。

本轮没有启动针对性训练。这32例已被用于诊断，应视为开发回归题；它们是4个模板的变体，不是32副独立新测试牌。真实6例来自评分牌，若用于训练，会消耗原评分牌的独立性，应另留未用于调参和课程构建的确认牌。未来课程划分需按底层模板/结构分开，不能把近似同题的换花色版本随机分到训练与测试两侧。
