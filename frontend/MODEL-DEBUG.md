# 模型对局观战

人机对局的“信息”是当前牌局的分析抽屉，不是本观战模式的入口。四家模型配置从主界面“模型调试”进入；两者保持清楚区分。

模型调试入口先显示四家配置，随后直接复用人机对战的绿色牌桌。每家可分别选择叫牌和出牌模型；点击“开始观战”继续当前共享牌局，从叫牌到13墩结算自动推进。换新牌使用牌桌右上角“新的一副”，进入下一副时重新确认模型配置。

本机当前可选出牌模型包括默认SL v2、原长训SL、早期SL、PPO试验模型，以及单独标注的DDS全知求解；叫牌可选默认SL和PPO试验模型。目录由电脑服务按实际存在的固定权重提供，不接受客户端提交文件路径，不自动接入正在训练中的SL v3。旧模型和PPO只作调试比较，出现在目录中不表示其棋力已超过当前默认模型。人机对战继续使用默认模型。

牌桌右下角支持0.5×、1×、2×、4×速度，暂停/播放及模型代打一步；一墩的四张牌打齐后会保留短暂停顿再收墩，单步时另按一次收墩。速度调节的是动作间隔，模型计算耗时另计。撤销会暂停并撤回上一步。模型调用失败停止播放，可重试；局面、服务、配置或播放状态变化时取消旧请求并拒绝迟到结果。

“全知观战”在四手明牌与南家视角之间切换，只影响界面。神经网络始终只接收行动控制者的合法可见信息。首攻后明手公开，明手出牌使用庄家选定的模型，而非明手座位选定的模型；这是桥牌的庄家控制规则。选择DDS的座位使用独立全知求解接口，不能将DDS表现当成神经网络能力。

“信息”按钮打开右侧抽屉并暂停。默认展示**上一步实际动作**及其模型输出快照，明确标注出牌家和模型控制者：叫牌显示动作概率；神经网络出牌显示手牌动作概率、52张牌的归属、价值头得分预测和权重哈希；DDS显示候选牌余墩。信息面板还可切换到当前未出牌局面，单独请求所选模型或DDS分析。没有胜率头时继续明确显示不可用。真值只在客户端对照。“记录”按钮单独展示公开叫牌和逐墩记录，关闭抽屉后主动点击播放才继续。

实现：`src/components/DebugWorkspace.tsx`负责观战生命周期，`src/components/MobileTable.tsx`通过observer参数复用牌桌，`src/observer.css`负责配置页及观战控件，诊断图表复用`ModelDiagnostics`。网关的`models.py`维护服务器端允许列表并按需缓存权重；`modelId`按单次请求路由，不修改默认策略对象，各模型共享推理锁。

手机已通过真实Wi-Fi的启动检查自动下载1.2.0，并调用App内安装器完成更新，系统包信息确认versionCode=5、versionName=1.2.0。本次没有ADB覆盖安装；`native-final.png`为安装后的真机自动出牌画面。
