## 运行

当前电脑可在仓库根目录执行：

```powershell
.\scripts\start-lan.ps1
```

脚本构建网页并启动模型 HTTP 网关与 DDS。当前网页和接口共用 `http://192.168.5.118:8000/`，手机 APK 已内置该分析地址。在设置中点击“测试连接”可检查模型和 DDS 是否就绪。IP 随网络变化时请按 [局域网说明](LAN.md) 更新。

仅开发页面时：

本机已有 Node.js 24.11.1。首次安装或重新克隆后：

```powershell
cd D:\code\BridgeMind\frontend
npm ci
npm run dev
```

打开 `http://localhost:5173/`。开发服务器监听 `0.0.0.0:5173`，同一 Wi-Fi 的手机打开终端输出的 WLAN 地址。本次机器 WLAN 地址为 `http://192.168.5.118:5173/`，IP 会随网络变化。如果电脑能打开而手机不能，请检查是否处于同一网络，以及 Windows 防火墙是否允许 Node.js 在专用网络接收入站连接。应用不自动修改防火墙。

```powershell
npm test
npm run build
npm run preview
```

`dist/` 是静态构建产物，可交给静态 Web 服务器部署。Vite 开发服务器仅供开发和局域网调试。

## 使用

主界面选择人机对战。你执南家叫牌，先选阶数，再点击具体叫品。出牌时自动切换当前南家或北家手牌，先选牌再确认；东西由当前模型自动行动。点击顶部BridgeMind返回主界面，或点击“模型调试”暂停并检查同一副牌。

分析面板的“配置分析服务”接受电脑上的 HTTP(S) 地址，并提供“测试连接”。电脑网关页面默认使用同源地址；APK 使用构建时的电脑地址。显式保存空地址可离线练习，不产生模拟 AI 或 DDS 建议。发起分析会暂停自动对手；分析完成后手动点击“继续自动对手”。

音效默认关闭，点击顶部音量图标开启；iPhone 上首次用户操作负责激活声音。字体、图标、牌面和音效均随项目提供，不依赖 CDN。浏览器建议 Safari / iOS 18+ 或现代 Chromium。Android 已通过 Capacitor 打包并在 Android 16 真机安装启动；iOS / App Store 包、Service Worker 与 PWA 离线安装尚未实现。

## 分析服务

完整请求和响应约定见 [局域网分析接口](../docs/frontend-analysis-api.md)。Python网关位于 `src/bridgemind/web/`，默认出牌模型为 `runs/play-sl-v2-20261026-2h/best.pt`，叫牌模型为 `runs/sl-pilot/last.pt`；启动脚本可通过 `-Checkpoint`、`-BiddingCheckpoint`指定其他权重。DDS返回全知余墩与全部等价最优牌。现有 `18765` 是DDS的TCP RPC服务，不能直接填写到浏览器。

```text
手机 / 电脑浏览器
    └─ HTTP POST → 电脑上的 Python 网关（8000）
                    ├─ AI：可见信息 → 现有纯网络出牌模型（CPU）
                    └─ DDS：完整牌局 → SolverClient → 本机 DDS TCP 服务
```

这是一张本地练习桌，四家牌都保存在浏览器内存中。界面隐藏和 AI 请求裁剪用于练习与模型信息边界，不构成多人在线游戏的防作弊边界。

## 结构

| 路径 | 职责 |
| --- | --- |
| `src/bridge/types.ts` | 统一座位、牌、叫品和对局类型 |
| `src/bridge/engine.ts` | 纯 TypeScript 桥牌规则、计分、练习对手 |
| `src/App.tsx` | 对局状态、交互、自动对手、设置、记录 |
| `src/components/PlayingCard.tsx` | 牌面、GSAP 飞牌路径 |
| `src/components/AnalysisPanel.tsx` | AI / DDS 请求生命周期和面板 |
| `src/api/analysis.ts` | 信息裁剪、HTTP 客户端、响应验证 |
| `src/audio.ts`、`public/sounds/` | Howler 音效与本地 WAV |
| `scripts/verify_backend.py` | 对现有 Python / OpenSpiel 后端交叉验证 |
